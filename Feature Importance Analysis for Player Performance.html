07 Academic Documentation

Methodology, Limitations & Governance

Data Cleaning & Feature Filtering

Seasons 2017–2018 through 2024–2025 across five European top flights. Restricted to players with primary positions Forward (FW), Midfielder (MF), or Defender (DF). Applied a minimum threshold of 450 minutes per player-club stint to filter out transient bench appearances.

Feature Leakage Safeguards

Target performance scores are constructed from weighted percentile rankings of core counting statistics (Goals, Assists, xG, Key Passes, Tackles Won). All direct score ingredients are strictly eliminated from the 23 model input features, forcing classifiers to rely on proxy activity metrics.

Model Hyperparameters

RandomForestClassifier: n_estimators=300, max_depth=None, min_samples_split=5, min_samples_leaf=2, class_weight='balanced', random_state=42

XGBClassifier: n_estimators=300, max_depth=6, learning_rate=0.05, subsample=0.8, colsample_bytree=0.8, objective='multi:softmax', num_class=3, random_state=42

Critical Limitations
  • Single Split: Uses a single temporal train/test split without k-fold cross-validation; the 1.84% accuracy gap has not been tested for statistical significance.
  • Multicollinearity: Minutes (Min) and 90s (90s) contain identical information, splitting importance weights between them.
  • Position-Blind Inputs: Position is not provided as a feature to the models, even though class thresholds are position-relative.
  • Correlation ≠ Causation: High feature importance reflects tree split utility, not player ability causation.
